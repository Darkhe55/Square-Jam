# 方块拼盘（Square Jam）

一个基于 Web 的「方块拼盘 / Square Jam」逻辑谜题游戏：把整个棋盘划分成若干正方形，数字表示它所在正方形的边长；原生 SVG 渲染，内置逻辑解题器、回溯求解器与自定义题板编辑器。

![方块拼盘](output/01-initial.png)

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5219/**（端口来自 `package.json` 的 `puzzle.port`，全项目唯一来源）。

> 也可以 `npm run dev`（不自动打开浏览器），或 `npm run build && npx vite preview --port 5219 --strictPort`。

## 游戏规则

- 把整个棋盘**恰好划分成若干正方形区域**，不能出现矩形，也不能留空；
- 数字格表示「该格所在正方形的边长」；一个正方形可以没有数字，也可以包含多个相同的数字；
- **tatami 规则**：任意内部顶点处不能出现四条区域边界相交 —— 即任何两个正方形都不能只在一个点接触；
- 每道内置题都有**唯一解**。

## 操作

| 操作 | 说明 |
|------|------|
| 左键拖拽 | 从正方形的一角拖到对角，松开即画出正方形；拖到已有正方形上松开 = 删除 |
| 左键单击 | 放置 / 删除 1×1 正方形 |
| 右键 | 删除该格所在正方形 |
| 方向键 | 移动键盘光标 |
| 回车 | 开始选正方形（起点）→ 方向键移到对角 → 再按回车完成 |
| `Esc` | 取消当前绘制；没有绘制时清空盘面 |
| 退格 / `Delete` | 删除光标所在正方形 |
| 撤销 / 重做 | 按钮或 `Z` / `Shift+Z`（`Y` 也可重做） |
| `C` / 提示一格 / 显示解 | 检查 / 提示一个参考解正方形 / 直接填入参考解 |
| `L` / `P` | 逻辑解题回放 / 暂停继续 |
| 拖拽棋盘外空白 / 中键拖拽 | 平移画布 |
| 滚轮 / `+` `-` `0` | 缩放 / 放大 / 缩小 / 复位 |
| `R` / `M` | 随机抽题 / 音效开关 |

## 自定义题板

- 侧边栏「自定义」打开编辑器，尺寸 **4×4 ～ 20×20**（建议上限 20×20）；
- 鼠标点击格子按 `空 → 1 → 2 → … → 20` 循环填写数字；键盘方向键移动、`1–9` 快速填写、`0` 清空、`.` / 退格清空，`10–20` 可直接点击格子循环选择；
- 「载入题板」用当前题面开始游戏并自动存入题库；「保存到题库」持久化；题库里自定义题支持**编辑**（重新打开时完整还原题面）与**删除**（二次确认）；
- 「求解」会显示是否**唯一解**（唯一解 / 多解 / 无解 / 超时）。

## 功能

- **题库**：7 道内置题（6×6 / 7×7 / 8×8 / 9×9 / 10×10），全部由生成器校验「唯一解 + 逻辑可推完」；
- **实时校验**：覆盖完整度、正方形与面积、数字与边长匹配、区域重叠、tatami 四点相交，违规格与顶点即时标红；
- **逻辑解题**：规则引擎逐帧回放并显示推理依据（数字线索唯一定位 / 唯一可行边长 / 反证），可暂停/停止；
- **提示一格 / 显示解**：提示优先补齐或纠正一个正方形，显示解直接填入参考解；
- **撤销/重做**：一次拖拽 = 一步；
- **进度保存**：自动保存当前盘面，刷新不丢失；
- **自定义题板**：见上一节；
- **音效/特效**：Web Audio 合成拨弦与水滴，无外部音频资源；
- **缩放/平移**：滚轮缩放、拖拽空白平移。

## 实现思路

- **状态**：`SquareState.regions = { x, y, size }[]`，每次手势产生一个 `Move`；正方形用 `((cell + 1) << 7) | size` 打包进 `Move.index`，因此撤销/重做与回放天然按「整块正方形」原子执行；
- **求解器**（`src/game/solver.ts`）：行优先选第一个未覆盖格，枚举以它为左上角的正方形边长。因为该格左上方向全部已覆盖，正方形不可能向左上扩张，所以它必定是所属区域的左上角；配合「正方形内数字必须等于边长」与增量 tatami 检查剪枝，可快速证明唯一解；
- **逻辑引擎**（`src/game/logic.ts`）只做可证明的推理：
  1. 数字线索的所有可能位置只剩一个 → 必放；
  2. 第一个未覆盖格的可行边长只剩一种 → 必放；
  3. 逐一试放并调用求解器反证，只有一种能继续求解 → 必放；
  4. 规则推不动时回溯补完（内置题均不需要，回放不会出现）；
- **校验器**（`src/game/validate.ts`）：由区域列表构建归属网格，逐项检查覆盖、正方形实际格数、数字匹配、tatami（内部顶点四格两两不同即四条边界相交）；
- **交互**（`src/game/interaction.ts`）：通过模板新增的可选 `GameInteraction` 扩展接管棋盘指针/键盘；拖拽时只更新预览层（不重建 SVG），避免打断指针捕获；模板默认的点击循环逻辑保持向后兼容。

## 项目结构

```
src/
  main.ts
  core/                         模板核心（通用）
    app.ts / ui.ts / view.ts    界面、交互、缩放、回放控制、可选拖拽交互扩展
    store.ts / library.ts       题库、进度、上次题目存储
    board.ts / types.ts         棋盘几何、类型契约
    audio.ts / fx.ts            音效与落子特效
  game/                         方块拼盘
    adapter.ts                  规则接入
    types.ts                    区域/线索类型与编码
    partition.ts                正方形划分几何、tatami、候选枚举
    state.ts                    盘面状态与 Move 打包
    validate.ts                 实时校验
    solver.ts                   回溯求解器（唯一解 / 显示解 / 反证）
    logic.ts                    逻辑解题回放计划
    render.ts                   SVG 渲染与命中
    interaction.ts              鼠标拖拽 / 键盘绘制
    puzzles.ts                  题库加载
    puzzles-data.ts             自动生成的内置题库
    square.css                  游戏皮肤
scripts/
  gen-puzzles.mjs               写入 puzzles-data.ts
  gen-config.mjs                随机出题器（tatami + 唯一解 + 逻辑校验）
  check.mjs                     题库深度审计（Node 直接 import .ts）
  ui-check.mjs                  Playwright + Edge 浏览器实测
  dev.mjs / _port.mjs           启动与端口
```

`scripts/check.mjs` 用 Node 24 直接 `import` 浏览器里的同一套 `.ts` 游戏代码，因此审计规则与实际游戏完全一致，不维护第二份规则实现。

## 命令

```bash
npm run dev       # 开发服务（127.0.0.1:5219）
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build

npm run check     # 题库深度审计（唯一解 / 参考解 / 逻辑推完 / 回放 / 编解码 / 交互几何）
npm run ui-check  # Playwright(Edge) 浏览器实测，截图输出到 output/
```

### 浏览器实测（Playwright + Edge）

先启动服务，再运行：

```bash
npx vite preview --port 5219 --strictPort
node scripts/ui-check.mjs
```

脚本使用 Edge（`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，可用 `EDGE_PATH` 覆盖），覆盖：

- 7 道内置题逐题「显示解」并通过校验；
- 鼠标从一角拖到对角画正方形、右键删除；
- 键盘回车开始/结束 + 方向键、`Esc` 取消；
- 撤销 / 重做 / 提示一格；
- 逻辑解题回放推满并解出；
- 错误高亮（四点相交 / 重叠 / 数字不符）；
- 自定义题板键盘录入 → 载入 → 求解（唯一解）→ 保存 → 编辑（还原）→ 删除（二次确认）。

截图输出在 `output/`（`01-initial.png` … `11-error-highlight.png`）。

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录（`vite.config.ts` 的 `/__store` 中间件）；静态部署或 `vite preview` 时自动降级到浏览器 `localStorage`。

## 已知限制

- 自定义题板键盘只直接支持 `1–9`，`10–20` 需要点击格子循环选择（鼠标任意数字都可用）；
- 自定义题板保存时不强制要求唯一解，需点「求解」查看是否唯一解；多解/无解会给出提示；
- 换行优先搜索对 20×20 且线索极少、无解或多解的题可能触发求解上限（界面会提示超时）；
- 极端情况下（浏览器窗口极小且高倍缩放）预览层与棋盘位置仍由同一 `viewBox` 计算，不会错位，但可能需要滚动查看。
